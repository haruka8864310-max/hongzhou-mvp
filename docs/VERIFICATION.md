## 實際瀏覽器限制

嘗試內建瀏覽器時回報 `The browser access host is unavailable`，未進行實際 Edge／Chrome 視覺及點擊驗收。DOM 整合、HTTP、語法與後端測試**不能取代**實際版面驗收；階段仍有這項驗收未完成。

可人工驗收：執行 `start_windows.bat` → 首頁確認 11 個無資料卡片 → 資料管理輸入公司有權使用的兩組歷史資料 → 跨市場比較核對圖表、實際日期與來源 → 豐興研究及雷達核對不足資料提示 → 備份。測試環境應先指定獨立 `HONGZHOU_DATA_DIR`，不在正式庫匯入測試資料。

未驗證：自動行情、外部來源可用率、任何策略收益、模型可靠預測能力、手機／公網、實際 Windows 離線檔案選擇器。不得將這些項目宣稱已完成。
