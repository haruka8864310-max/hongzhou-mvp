# 市場情報開發計畫

依 2026-11-04 新需求取代原營運順序，沿用同一專案與資料目錄。

## 第一批：市場總覽、跨市場比較

首頁與新行情表、來源與時效、手動／CSV 全檔驗證、歷史變化與過期提示、台幣／公噸與指數、日期對齊、位移報酬相關。舊程式保留 `/legacy`。

驗證空資料、錯誤輸入、整批回滾、缺漏／過期／未來匯率、磅／短噸換算、原資料與備份保留。API 已測，實際瀏覽器驗收待完成。

## 第二批：豐興研究、機會雷達

方向頻率基準、逐期時間序列回測、持平基準、樣本及不確定性；銅波動、日台背離、匯率、連續走勢與本機門檻。

驗證未來結果不改變歷史預測、週頻限制、過期排除與門檻持久化。API／演算法已測，瀏覽器驗收待完成，不宣稱模型可靠或策略獲利。

## 第三批：授權來源及成熟工具

1. 先確認各資料集公司內部保存、顯示、非顯示分析的權利，再做自動連接器；低頻統計不冒充即時行情。
2. 完成瀏覽器操作驗收後，整合本機打包 Lightweight Charts，保留授權與署名。
3. 歷史與基準穩定後才在隔離環境評估 Darts，固定回測切分，不以測試集調參。
4. vectorbt 附 Commons Clause，非必要不導入；OpenTerminal 不承襲未確認權利的端點。
5. 增加修訂稽核、完整歷史檢視、匯率來源選擇與官方檔案欄位對映。

各批須有獨立資料庫測試、升級前備份、前後端驗證與 Git commit。瀏覽器無法驗證時明確記錄。公網／手機關閉，營運功能暫停擴充。
