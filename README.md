# 弘洲營運助手

版本：0.2（本機優先、Windows 11 專用）

## 專案定位
這是台灣廢鐵回收公司內部營運系統，目標是在 Windows 11 單機上快速建立可用的營運資料與報表，保留後續手機安全存取的擴充空間，避免公網暴露與未驗證權限造成風險。

## 目前狀態
### 已完成
- Python FastAPI + SQLite 本機資料庫架構
- 客戶、行情、進出貨資料表與簡單 API
- 本機備份與 ZIP 移機備份流程
- 基本 CSV 匯出與還原檔案驗證
- 測試基礎（pytest）與資料庫初始化測試
- 專案治理文件與 .gitignore

### 未完成
- 使用者登入與角色權限
- 交易修改 / 刪除與稽核紀錄
- 廢鐵、廢鋼、廢鋁等進出貨成本計算與庫存平均成本
- 每筆交易毛利、應收應付、現金流與報表
- 豐興/COMEX/LME/SHFE 來源整合與法務授權驗證
- 客戶地圖、回訪提醒與開發提醒功能
- 手機安全存取、部署與認證準備

### 目前存在風險
- 尚未確認營運規則與會計口徑，不能直接將庫存總量當作帳冊
- 主資料庫與備份仍位於本機硬碟，需額外複製到其它媒體以降低損失風險
- 市場行情來源若未完成官方授權核對，不能直接納入正式報表
- 未完成權限管理前，禁止串接手機或遠端存取

## 安全與資料處理原則
- 資料默認保存在 `%LOCALAPPDATA%\HongzhouAssistant`
- 不提交真實客戶資料、交易、財務資料、密鑰或正式營運文件到 Git
- 本機只開啟 `127.0.0.1`，不設置 `0.0.0.0` 或公網暴露
- 國內/國際價格需保留來源標示與授權確認資訊

## 啟動方式
1. 安裝 Python 3.11+
2. 在專案目錄執行 `start_windows.bat`
3. 開啟 `http://127.0.0.1:8765`
4. 若需要還原備份，先關閉 app，再執行 `restore_windows.bat`

## 待確認事項
- 公司是否採用哪套交易損益計算規則：毛利 / 淨利 / 平均成本 / 最後入庫成本
