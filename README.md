# 弘洲金屬市場情報與決策分析系統

在原 hongzhou-mvp 開發的 Windows 本機 Web App，保留 Python FastAPI + SQLite。優先研究市場、採購／銷售時機與價格風險；毛利、庫存、記帳、客戶功能暫停擴充，原程式與資料保留於 `/legacy`。

## 現在可用：真實金屬月度市場研究

首頁為「市場總覽」，顯示本期市場重點與三個固定代表鋼材。按 **更新金屬與代表鋼材**，可取得 World Bank 銅／鋁／鎳／鐵礦砂、BLS 美國廢鋼與廢銅指數及工程會訪價。「金屬市場趨勢」提供搜尋、分類、進階規格、代表規格保存與CSV／Excel匯入。操作、實測結果與資料不足限制見 [本輪修復紀錄](docs/DATA_REPAIR_20261104.md)。請保留啟動視窗；程式更新後需重啟服務。

1. 選指標 A、B、圖表期間、原始／台幣／標準化比較，按「保存參數並執行分析」。可看最新觀察、上期及3／6／12月變化、長期圖表、逐月實際值與匯率依據。
2. 「趨勢計價」可切換原幣、台幣或原幣／台幣共同首月100。只有同月至少10筆日匯率才換算，不以今天匯率回填歷史。匯率歷史範圍仍從既有「資料與設定」調整後更新；目前最高5年，因此更長金屬歷史不一定有台幣對應值。
3. 「領先指標研究」使用同一組 A、B 及保存期間，列出同期、領先1／2／3月的原始月報酬相關、前後半段穩定度及樣本數。它是描述性研究，不是經驗證的預測模型。
4. 「市場機會雷達」增加實際月資料的連續走勢、異常月變動及美元銅價／匯率分解。每個訊號附月份、來源、公式與限制；台灣只有單月資料時不捏造背離訊號。
5. 「豐興行情研究」可按輸入／CSV匯入入口使用既有行情表單；有週歷史後顯示基準混淆矩陣及外部因子研究。今天下載的修訂快照不會回填成過去已知版本；缺版本或樣本時明示尚無法建立可靠模型。

月度來源、更新間隔、期間、門檻、A／B、計價及比較模式均可在網頁保存。背景工作沿用既有 APP 背景更新開關；每30秒的頁面刷新只讀本機，不每30秒下載來源。來源失敗保留資料與上次成功時間。首次升級v4先備份，再新增月度表，不重建原有DB；修訂以新版本追加，保留原版本。

實測與授權詳見 [月度來源與驗收](docs/MONTHLY_MARKETS.md)。不要把 World Bank 月均值標成 COMEX 即時期貨，或把 BLS 指數當每公斤收購價。

## 啟動

安裝 Python 3.11+，執行 `start_windows.bat`，開啟 **http://127.0.0.1:8765**。資料仍在 `%LOCALAPPDATA%\HongzhouAssistant\hongzhou.db`；測試可設定 `HONGZHOU_DATA_DIR`。僅以 `127.0.0.1`、單一程序啟動，不使用 `--workers`、`0.0.0.0` 或遠端轉發。本版沒有登入與手機存取。

請勿雙擊 `market.html`／`index.html`、使用 VS Code Live Server 或 `file://` 預覽來操作。這些頁面不是獨立的靜態 APP，必須由同一個 FastAPI 服務提供。啟動檔現在只在依賴缺少時安裝，並透過 `run_local.py` 等待 `/api/health` 確認目前版本與 SQLite 正常後才開瀏覽器；已被其他程式、舊版服務或不同資料目錄占用時會明確停止，不開錯頁面。保留啟動視窗，按 Ctrl+C 關閉服務。日誌存於資料目錄 `logs/server-日期-時間-PID.log`；失敗時會顯示檔名及錯誤尾段。

若看到「本機服務未連線」，先確認啟動視窗顯示「服務與 SQLite 已就緒」，再使用該視窗印出的 `http://127.0.0.1:8765`，按頁面「重新連線」。前端所有 API 都使用當前網頁相同的來源與連接埠，不跨連另一個服務，也不開啟 CORS 通配。無豐興週資料時，選單會說明原因且評估按鈕停用；匯率不會冒充豐興歷史。

## 操作

介面已改為柔和亮色系。首頁「更新真實匯率」可立即取得資料，預設啟動後背景更新央行日參考匯率，不需要修改程式碼或 API 金鑰。首次更新會補入設定分析期間加 30 日緩衝的真實歷史。

**資料與設定 → 追蹤與分析設定**：調整追蹤市場、背景更新開關、來源（央行／Frankfurter）、每 1 小時／6 小時／每日檢查、分析天數（30–1825）、異常波動門檻及預設比較市場。儲存至 SQLite，重啟保留；取消追蹤不刪除歷史。APP 關閉時不更新，下次開啟依最後檢查時間接續。網頁的每 30 秒重新整理只讀取本機資料，不每 30 秒請求外部來源。

**資料來源狀態**：分列「自動更新成功」「資料延遲」「來源無法取得」「需要手動輸入」，保留最後成功、最後檢查、來源資料集更新日與實際報價日。下載成功不代表報價即時；來源逐筆發布時間未知時明確顯示「未提供／首次取得」，不以本機時間冒充發布時間。

- **市場總覽**：11 個追蹤項目涵蓋豐興廢鋼／鋼筋、日本 H2、美國廢鋼、COMEX HG、LME 銅、SHFE 銅、鐵礦砂、USD／JPY／CNY 兌台幣。每個規格與合約分卡，列出最新價格、單位、行情日、來源、發布／本機更新時間、延遲及過期提示。可篩選市場、自訂異常門檻。無資料時不顯示價格。
- **資料管理 → 新增一筆行情**：填入規格／稅別／交貨條件、合約／報價口徑、來源網址及內部使用授權依據。來源發布時間以台灣時間輸入。不能輸入未來行情；不把手動資料標為即時。
- **資料管理 → CSV 匯入**：下載空白範本，UTF-8 儲存，最多 5000 筆／2 MB。頁面可展開欄位與項目代碼。`published_at` 須含時區，例如 `2026-11-01T15:00:00+08:00`；`delay` 是 `unknown`／`delayed`／`eod`。任一列錯誤或重複，整批取消，不覆寫原紀錄。現階段沒有資料修訂介面，請核對後再匯入。
- **跨市場比較**：選兩組序列、日期及「共同首日 = 100」或「TWD／公噸」。預設同日觀察、不補值；可選向前沿用最近報價，限制 0–14 天。圖表與表格顯示實際行情日、匯率日、來源及缺漏日期數。
- **豐興行情研究**：選廢鋼序列，執行基準模型。至少 53 筆、每期間隔 5–9 日；持平週也必須記錄。資料不足、不規則或發布過晚拒絕推估；過期資料僅顯示歷史研究。機率為加一平滑歷史頻率，未經校準，不代表可靠下週預測。
- **市場機會雷達**：設定波動、匯率及連續次數門檻後掃描，設定存於 SQLite。訊號列出原因與資料時間；過期、缺資料或間隔過長不產生新訊號。沒有訊號不代表沒有風險。
- **資料管理 → 備份**：立即備份到資料目錄的 `backups`，或下載完整移機 ZIP。還原表單仍在 `/legacy`；離線可用 `restore_windows.bat`，先關閉服務。

## 分析口徑與限制

- 公噸 1000 kg、磅 0.45359237 kg、美制短噸 907.18474 kg。匯率必須為「1 外幣 = X TWD」，不可混入 100 JPY 報價。
- 外幣換算只取行情日以前 7 日內匯率，不使用未來匯率。優先使用設定明確選擇的自動來源；若不存在且手動匯率規格不唯一，暫停換算。缺資料日期略過並計數。
- 7／30 日變化的基準是距目標日最多向前 7 日的最近觀察，UI 列出實際基準日，不保證精確七日或三十日報酬。
- 換算不消除品質、稅別、FOB／CFR、運費、期貨期限與交易時段差異，不推算跨品級套利價差。
- 位移相關採兩序列相同觀察起訖區間的原幣報酬；正位移表示 A 領先 B 若干日。至少 8 組且報酬非固定才提供係數，不宣稱因果或統計顯著性。
- 週模型以最初 26 次變化起訓、逐期擴展視窗，只使用過去方向，對照「永遠猜持平」。命中率 95% Wilson 區間不是價格預測區間；時間序列相依會影響區間解讀。未驗證策略獲利或模型優於基準。
- 日參考匯率預設央行 BP01D01，供國內研究參考，不是銀行買賣價；JPY/TWD、CNY/TWD 由同日 TWD/USD 分別除以 JPY/USD、CNY/USD。Frankfurter 備選上次實測 HTTP 522。新增月度引擎與既有日行情分表、分單位保存；交易所即時牌價仍未接入。

## 升級與保護

版本 2 新增 `market_quotes`、`market_settings` 與索引。既有資料庫首次加行情表前自動以 SQLite backup 備份；不清除原 `prices`、`customers`、`trades`。舊行情缺規格與來源資訊，不自動混入新分析。

版本 3 在升級前再次備份，僅新增來源狀態表及行情來源更新／發布時間已知旗標，不重建資料庫。自動來源重複日期跳過；若原來源修訂，保留原值、顯示衝突數，待人工核對，不默默覆寫。切換來源保留歷史，停用來源的卡片會註明。

還原先驗證完整性、欄位、關聯與版本，再備份現有資料並以 SQLite backup 還原；舊版還原後加表，較新版拒絕。還原鎖僅限同一程序，操作時先停止其他使用者操作。保留離機備份；DB 未加密，依賴 Windows 使用者及磁碟保護。不得提交真實資料、CSV、Excel、DB、ZIP、金鑰至 Git。

## 測試

```powershell
.venv\Scripts\python -m pip install -r requirements-dev.txt
New-Item -ItemType Directory -Force .test-runs
.venv\Scripts\python -m pytest -q --basetemp=.test-runs/manual-run
```

`--basetemp` 請用新的測試目錄名稱；pytest 會清除此目錄。fixtures 在服務啟動前指向獨立暫存資料庫，不操作正式資料。

見 [驗收紀錄](docs/VERIFICATION.md)、[來源研究](docs/MARKET_SOURCES.md)、[開源工具評估](docs/OPEN_SOURCE_REVIEW.md)、[開發計畫](docs/DEVELOPMENT_PLAN.md)。

前端整合測試另需 Node.js 與開發依賴：`pnpm install --frozen-lockfile` 後執行 `node --test tests/market-ui.test.cjs`。測試用 jsdom 操作實際 HTML／JavaScript，連線獨立 FastAPI 程序及測試庫；正式啟動仍只需 Python。

真實網路來源煙霧測試：`.venv\Scripts\python scripts/check_live_rates.py`。只在 `.test-runs/live-rates-*` 建立獨立資料庫及結果 JSON，需連外；標準測試不連網。2026-11-04 實測央行匯入 777 筆、三個幣別各 259 筆，可比較對齊 241 日；當次資料截至 2026-10-30，正確標示延遲。這些數據是測試證據，不保證來源未來持續可用。
